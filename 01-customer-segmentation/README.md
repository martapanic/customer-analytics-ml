# Customer Segmentation & Communication Strategy

Part 1 of the **AI for Communication and Marketing** project.

This analysis focuses on customer segmentation using both **RFM scoring** and **K-Means clustering** to identify valuable customer groups and translate them into differentiated marketing strategies.

## Methods

- Exploratory Data Analysis
- RFM segmentation
- Feature scaling
- K-Means clustering
- Elbow Method
- Silhouette Score
- PCA
- Cluster profiling
- Marketing strategy definition

## Key Findings

RFM analysis identified the customer segments contributing most strongly to revenue, while K-Means provided complementary behavioral personas.

One of the main findings was the **Premium Lifestyle** cluster, representing **23.8% of customers while generating 51.6% of total revenue**.
